# Assignment Review and Transparent Design

The Transparent Design workspace preserves the faculty’s original assignment and provides an editable working version. Standard Review is deterministic and checks only visible signals: task/product language, stages, criteria language, explicit SLO links, practice links, and unusually long unstructured directions. Results use "Looks clear," "Review suggested," "Information not found," and "Faculty decision needed"; they are not pedagogical verdicts.

TiLT review uses the existing Purpose, Task, and Criteria for Success framework. Faculty edit or ignore every suggestion. The student-facing transparent version is assembled only from faculty text and confirmed TiLT fields; missing material is an explicit faculty-input placeholder.

AI-Assisted Review remains disabled. A future optional service may interpret discipline-specific context or less-explicit wording, but it must be separately labeled and never replace faculty judgment or deterministic findings.
