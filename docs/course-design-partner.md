# Course Design Partner milestone

The Course Design Partner centers the shared `CourseRecord` on backward design: Outcomes → Assessments → Learning Experiences → Alignment. Document extraction, deterministic review, Activity Builder, TiLT, local persistence, provenance, and Prompt Handoff are preserved as supporting capabilities.

## Three layers

- **Deterministic analysis:** parsing, explicit relationships, observable review signals, TiLT presence, and provenance. Findings are cautious and never pedagogical verdicts.
- **Curated design intelligence:** reusable outcome-improvement patterns supply structured choices and editable starting language. The current milestone implements this layer for Outcomes.
- **Future generative layer:** Prompt Handoff remains a vendor-neutral, editable bridge for discipline-specific interpretation. Integrated AI is disabled.

Faculty-approved revisions overwrite the active SLO wording in `CourseRecord`, so alignment, assessment links, and activity recommendations use the revised outcome. `outcomeDesignDecisions` retains the chosen pattern, original wording, guidance, revision, and source for local provenance.

Assessment redesign, learning-experience design paths, alignment actions, TiLT, and AI-aware design are extension points for the same interaction pattern: context → recommendation → choice → creation → revision.
