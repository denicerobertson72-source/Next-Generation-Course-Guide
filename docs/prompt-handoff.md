# Prompt Handoff

Prompt Handoff creates a vendor-neutral, editable prompt from the minimum relevant local course context and deterministic findings. It makes no OpenAI or other provider API call, and it does not automatically send documents to an external service.

Faculty choose whether to copy the prompt into an AI assistant available through an institution or personal account. They should follow institutional guidance, avoid identifiable student information, and review the external provider's data-use policies. Long source documents are not dumped into prompts; the app instead asks faculty to attach the source separately if needed.

Supported task contexts include whole-course review, outcomes, alignment, active learning, transparent design, AI-and-assignment design, and AI-use guidance. Each handoff records a concise source summary. Optional pasted external feedback is saved only as faculty reference; Course Guide does not interpret or apply it.

Integrated AI Review remains a future, separately governed capability. It is disabled in this prototype.
